Програма [GOLD_code_correlation_analysis], версія 2
====================================================

USER MANUAL — короткий посібник

1. Параметри
   - Степінь (n) — степінь базових примітивних поліномів k_b(X).
   - Тип кореляції — Періодична або Аперіодична (АКФ / ВКФ).
   - Критерій впорядкування — СРЗН+СКВ, СРЗН, Макс, Мін.
   - K — кількість кодів Голда з мінімальними кореляціями.

2. START
   Запускає обчислювальну програму (config/gold.conf → compute).
   Після завершення оновлюються поля індикації та стають доступними
   кнопки результатів.

3. Індикація
   - prim поліноми (10_Б, 2_Б тощо)
   - оптимальні пари (10_пар, 2_пар)
   - ансамблі Q (16, 2, +/-)

4. Кнопки результатів
   АКФ_1, АКФ_2, ВКФ_1, ВКФ_2 — автокореляція / взаємна кореляція.
   SRT_1, SRT_2, USRT_1, USRT_2 — відсортовані результати.

5. PRINT
   Звіт у output/report.txt.

6. Опції
   Шляхи до compute та viewer; збереження у config/gold.conf.

7. RESET
   Скидання параметрів і індикації до початкових значень.

8. FINISH
   Вихід з програми.

Підключення зовнішньої програми:
   Замініть compute у gold.conf на ваш .exe або python3 script.py,
   якщо вона записує output/summary.json та файли acf_1.txt … usrt_2.txt.
